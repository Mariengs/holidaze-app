# Holidaze – Project Exam 2

A modern accommodation booking platform built with React Router v7, Tailwind CSS, and the official Holidaze API.  
Users can browse venues, make bookings, and manage listings depending on their role.

---

## Features

### All Users

- Browse all venues
- Search for venues
- View venue details by ID
- View availability and booking calendar
- Register as Customer or Venue Manager (requires **@stud.noroff.no**)

### Customers

- Log in / log out
- Create bookings
- View upcoming bookings
- Update avatar/profile picture

### Venue Managers

- Log in / log out
- Create, edit, and delete venues
- View bookings for owned venues
- View **My Venues** on profile page
- Update avatar/profile picture

### Additional Functionality

- Extended calendar showing more dates
- Full CRUD support for venues
- Responsive UI with Tailwind CSS
